Biggest single gain

80% of the reference's work was padding

The reference pads every passage to 512 tokens. The average practice passage has 100.

We sort by length and cut batches to a token budget of 8,192, padded only to the next multiple of 8. Inputs of 32 tokens or fewer form their own batches and run in FP32.

Across all 100,000 passages: 51.2 M token positions become 10.4 M, padding drops from 80.4% to 3.7%.

The finding that mattered

The official check sees 2,000 passages. The rule covers all 100,000

One passage below cosine 0.999 scores the whole run zero. Plain FP16 passed the official 2,000 at 0.999663, so it looked safe.

We embedded all 100,000 practice passages with our FP32 path and compared. Plain FP16 failed on 2. An FP32 residual stream still failed on 1. Every passage below 0.9999 had 23 tokens or fewer.

Inputs of 32 tokens or fewer now run in FP32. They are 33% of passages but 5.5% of tokens, so the cost is 3%, and the 100,000-passage worst case is 0.999992.

Live queries · 15% of the score

One query at a time, replayed through a CUDA Graph

bench.py sends each query alone, in arrival order. Eager PyTorch launches hundreds of small kernels per query; a captured CUDA Graph launches the whole 12-layer forward in one call.

Queries are short, so they take the FP32 path too. That costs about 2 ms per query and removes the precision risk on the hidden trace.

GPU service time per query, ms (median of 1,500) EagerCUDA Graph

Official replay of the 1,500-query trace with the submitted file: p50 4.40 ms, p99 8.24 ms, 0 violations, min cosine 0.9999999. The p99 includes waiting behind earlier queries of a burst. An FP32 query reads 440 MB of weights, which a graph cannot remove.

  • Same model. BAAI/bge-base-en-v1.5 checkpoint, unchanged weights and architecture.
  • Allowed precision only. FP16 and FP32; no INT8, BF16 tested and rejected.
  • Exact tricks. Fused QKV and CLS-only last layer give cosine 1.0000000 in FP32.

  • Tested edges. Empty text, Unicode, over-512 truncation, ordering: 29 cases pass on GPU.

All numbers measured on an NVIDIA GeForce RTX 3050 6GB Laptop GPU (Ampere, sm_86), torch 2.15 + CUDA 13.2, 24 Nov 2026. Reference baseline: reference.py on 5,000 passages (its cost per passage does not depend on the text, since it pads everything to 512).
